World map images (put in public/ folder):

1) Full world (World Map button / overview background):
   world-map.png

2) Per continent (click a region to open):
   world-map-north.png   — Ashen North
   world-map-middle.png  — Verdant Middle
   world-map-south.png   — Sunken South

Size: 1600×900 or 1920×1080 recommended.
Pins use the same x/y % as admin (north = top third, etc.)

Optional .env URLs:
  VITE_WORLD_MAP_URL
  VITE_WORLD_MAP_NORTH_URL
  VITE_WORLD_MAP_MIDDLE_URL
  VITE_WORLD_MAP_SOUTH_URL
